# Οδηγός Φοιτητών — iRobot Create + LiDAR (Webots R2025a)

**ESDA Lab — Εισαγωγή στα Ρομποτικά Συστήματα**

**Εργασία:** Ανάπτυξη και αξιολόγηση αυτόνομης αποφυγής εμποδίων.

## Στόχος

Σκοπός της εργασίας είναι η ανάπτυξη ενός Python controller, ο οποίος διαβάζει δεδομένα από αισθητήρα 2D LiDAR, υπολογίζει τις ελεύθερες αποστάσεις εμπρός, αριστερά και δεξιά και ελέγχει αυτόνομα την κίνηση του ρομπότ iRobot Create.

Η υλοποίηση θα πραγματοποιηθεί στο περιβάλλον προσομοίωσης **Webots R2025a**.

Δεν απαιτείται εγκατάσταση ROS και δεν ζητείται υλοποίηση SLAM.

## Τι παρέχεται / Τι υλοποιείτε

Στο GitHub repository του μαθήματος παρέχονται:

- Τρία περιβάλλοντα προσομοίωσης (worlds) με το iRobot Create και εγκατεστημένο αισθητήρα LiDAR.
- Ένας αρχικός Python controller με συγκεκριμένα σημεία συμπλήρωσης (TODO).
- Βοηθητικά αρχεία και εργαλεία για τη λειτουργία της προσομοίωσης και την ανάλυση των αποτελεσμάτων.

**Δεν παρέχεται έτοιμος αλγόριθμος αποφυγής εμποδίων.** Οι φοιτητές καλούνται να υλοποιήσουν τη λογική του controller.

Η αρχική εκτέλεση του κώδικα θα σταματήσει στο `NotImplementedError`. Πρόκειται για αναμενόμενη συμπεριφορά, καθώς ο controller είναι ημιτελής.

## Βήμα 2 — Άνοιγμα της προσομοίωσης

1. Εκκινήστε το Webots R2025a.
2. Επιλέξτε **File → Open World**.
3. Μεταβείτε στον φάκελο του repository και ανοίξτε:

   `create/worlds/01_sparse.wbt`

4. Στο Scene Tree εντοπίστε το ρομπότ `Create`.
5. Ελέγξτε ότι χρησιμοποιεί τον controller `student_lidar`.
6. Εντοπίστε τον αισθητήρα LiDAR στο `bodySlot`, με όνομα `esda_lidar`.

Στη συνέχεια, ανοίξτε το αρχείο:

`create/controllers/student_lidar/student_lidar.py`

Αυτό είναι το αρχείο Python που θα επεξεργαστείτε.

## Βήμα 3 — Μελέτη του αισθητήρα LiDAR

Πριν ξεκινήσετε τον προγραμματισμό:

1. Εντοπίστε τον αισθητήρα `Lidar` στο Webots.
2. Καταγράψτε τις παραμέτρους `horizontalResolution`, `fieldOfView`, `minRange`, `maxRange`.
3. Μελετήστε τις εντολές `robot.getDevice('esda_lidar')`, `lidar.enable(step_ms)` και `lidar.getRangeImage()`.
4. Εξετάστε πώς αναπαρίστανται οι 360 μετρήσεις απόστασης.
5. Απορρίψτε μη έγκυρες μετρήσεις (`inf`, `NaN`, μη θετικές τιμές).
6. Επαληθεύστε τη γωνιακή αντιστοίχιση των μετρήσεων, ώστε να εντοπίζονται σωστά οι τομείς εμπρός, αριστερά και δεξιά.

## Βήμα 4 — Υλοποίηση Python Controller

Στο αρχείο `student_lidar.py` συμπληρώστε τα ακόλουθα:

**TODO 1 — Επεξεργασία μετρήσεων LiDAR**

Υλοποιήστε τη συνάρτηση:

`sector_min(ranges, start_deg, stop_deg)`

Η συνάρτηση θα υπολογίζει την ελάχιστη έγκυρη απόσταση σε συγκεκριμένο γωνιακό τομέα.

**TODO 2 — Αλγόριθμος λήψης αποφάσεων**

Υλοποιήστε τη συνάρτηση:

`decide(front_m, left_m, right_m)`

Ο controller θα πρέπει να υποστηρίζει τουλάχιστον τρεις καταστάσεις:

- `FORWARD`: κίνηση προς τα εμπρός.
- `SLOW`: μείωση ταχύτητας όταν ανιχνεύεται εμπόδιο.
- `TURN`: αλλαγή κατεύθυνσης για αποφυγή εμποδίου.

**TODO 3 — Έλεγχος κινητήρων**

Υπολογίστε τις αποστάσεις στους τρεις τομείς, καλέστε τη συνάρτηση `decide()` και εφαρμόστε τις κατάλληλες ταχύτητες στους δύο κινητήρες με `setVelocity()`.

**TODO 4 — Καταγραφή μετρήσεων**

Καταγράψτε σε αρχείο CSV:

- Χρόνο προσομοίωσης.
- Αποστάσεις LiDAR.
- Ταχύτητες κινητήρων.
- Κατάσταση ελέγχου.
- Συμβάντα αποφυγής εμποδίων.

Ενδεικτική λογική: όταν η εμπρόσθια απόσταση είναι μικρότερη από το `FRONT_LIMIT_M`, το ρομπότ στρίβει προς την πλευρά με τον μεγαλύτερο ελεύθερο χώρο. Όταν η απόσταση είναι μικρότερη από το `CAUTION_LIMIT_M`, μειώνει την ταχύτητά του. Διαφορετικά, συνεχίζει ευθύγραμμα.

Μετά την ολοκλήρωση του controller:

## Συνήθη προβλήματα

- **`NotImplementedError`:** Δεν έχει ολοκληρωθεί κάποιο TODO.
- **`getDevice` returns None:** Ελέγξτε το όνομα του αισθητήρα στο Scene Tree.
- **Δεν ενημερώνεται ο controller:** Αποθηκεύστε το Python αρχείο και κάντε Reset.
- **Σφάλμα PROTO:** Ελέγξτε την πρόσβαση στους επίσημους πόρους του Webots.
- **Εμφανίζεται αρχείο `.c`:** Αφορά βοηθητικό controller του αρχικού παραδείγματος. Ο controller της εργασίας είναι σε Python.
