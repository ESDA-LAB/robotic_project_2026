# Οδηγός Εργασίας Δύο Φοιτητών: iRobot Create + LiDAR (Webots R2025a)

**ESDA Lab — Εισαγωγή στα Ρομποτικά Συστήματα**

**Εργασία:** Ανάπτυξη και αξιολόγηση αυτόνομης αποφυγής εμποδίων.

## Στόχος

Σκοπός της εργασίας είναι η ανάπτυξη και αξιολόγηση ενός αυτόνομου κινητού ρομπότ στο περιβάλλον προσομοίωσης **Webots R2025a**.

Θα χρησιμοποιηθεί το ρομπότ **iRobot Create**, το οποίο διαθέτει αισθητήρα **LiDAR** για τη μέτρηση αποστάσεων από εμπόδια.

Οι φοιτητές θα συνεργαστούν για την υλοποίηση ενός συστήματος που θα μπορεί:

- Να ανιχνεύει εμπόδια μπροστά, αριστερά και δεξιά.
- Να αποφασίζει αν θα κινηθεί ευθεία, θα μειώσει ταχύτητα ή θα στρίψει.
- Να ελέγχει αυτόνομα τους κινητήρες του ρομπότ.
- Να καταγράφει δεδομένα λειτουργίας σε αρχεία CSV.
- Να αναλύει τα δεδομένα και να δημιουργεί γραφήματα.
- Να αξιολογεί τη συμπεριφορά του ρομπότ σε τρία διαφορετικά περιβάλλοντα.

Η ανάπτυξη θα πραγματοποιηθεί σε **Python**, χρησιμοποιώντας το API του Webots.

**Δεν απαιτείται εγκατάσταση ROS ή ROS 2 και δεν ζητείται υλοποίηση SLAM.**

## Βήμα 2 — Άνοιγμα της προσομοίωσης

1. Εκκινήστε το Webots R2025a.
2. Επιλέξτε **File → Open World**.
3. Μεταβείτε στον φάκελο του repository και ανοίξτε:

   `create/worlds/01_sparse.wbt`

4. Στο Scene Tree εντοπίστε το ρομπότ `Create`.
5. Ελέγξτε ότι χρησιμοποιεί τον controller `student_lidar`.
6. Εντοπίστε τον αισθητήρα LiDAR στο `bodySlot`, με όνομα `esda_lidar`.

Στη συνέχεια, ανοίξτε το αρχείο:

`create/controllers/student_lidar/student_lidar.py`

Αυτό είναι το αρχείο Python που θα επεξεργαστείτε.
Σημαντικό: Ο αρχικός controller δεν είναι ολοκληρωμένος. Περιλαμβάνει ασκήσεις TODO που πρέπει να συμπληρωθούν από τους φοιτητές. Κατά την αρχική εκτέλεση, το ρομπότ παραμένει ακίνητο. Η εμφάνιση NotImplementedError μετά την ενεργοποίηση των ημιτελών συναρτήσεων είναι αναμενόμενη μέχρι να ολοκληρωθεί η υλοποίηση.

6. Επαληθεύστε τη γωνιακή αντιστοίχιση των μετρήσεων, ώστε να εντοπίζονται σωστά οι τομείς εμπρός, αριστερά και δεξιά.

## Ανάλυση αποτελεσμάτων με Python (analyze_csv.py)

Μετά την ολοκλήρωση του controller, οι φοιτητές θα χρησιμοποιήσουν τα αρχεία CSV για να αναλύσουν τη συμπεριφορά του ρομπότ.

Η καταγραφή πραγματοποιείται από το `student_lidar.py`, ενώ η ανάλυση από το `create/tools/analyze_csv.py`.

### 1. Δημιουργία αρχείου CSV (TODO 4)

Ο controller διαθέτει ήδη τον μηχανισμό δημιουργίας του αρχείου:

`create/results/run_log.csv`

Ο φάκελος `results` δημιουργείται αυτόματα κατά την εκκίνηση του controller.

Ο Φοιτητής Β πρέπει να συμπληρώσει το TODO 4, ώστε να καταγράφονται οι μετρήσεις σε κάθε βήμα της προσομοίωσης.

Το CSV πρέπει να περιλαμβάνει τις ακόλουθες στήλες:

| Στήλη | Περιγραφή |
|---|---|
| `time_s` | Χρόνος προσομοίωσης |
| `front_m` | Απόσταση εμπρός |
| `left_m` | Απόσταση αριστερά |
| `right_m` | Απόσταση δεξιά |
| `left_speed` | Ταχύτητα αριστερού κινητήρα |
| `right_speed` | Ταχύτητα δεξιού κινητήρα |
| `mode` | Κατάσταση FORWARD, SLOW ή TURN |
| `avoidance_events` | Αθροιστικός αριθμός εισόδων στην κατάσταση TURN |
| `bumper_events` | Συμβάντα επαφής, εφόσον μετρώνται |

**Σημαντικό:** Στην αρχική έκδοση δεν μετρώνται συμβάντα επαφής. Η τιμή `0` στο `bumper_events` δεν σημαίνει ότι δεν υπήρξαν συγκρούσεις.

### 2. Διατήρηση αποτελεσμάτων

### 4. Ανάλυση ενός αρχείου CSV

**Έλεγχος πριν από την ανάλυση**

Το αρχικό `run_log.csv` περιέχει μόνο τις επικεφαλίδες, μέχρι να ολοκληρωθεί το TODO 4. Εάν εκτελέσετε την ανάλυση πριν καταγραφούν μετρήσεις, θα εμφανιστεί σχετικό ενημερωτικό μήνυμα.

Για να δείτε τη σωστή σύνταξη της εντολής, εκτελέστε:

```powershell
python create/tools/analyze_csv.py
```

Το πρόγραμμα εμφανίζει επίσης κατανοητά μηνύματα όταν ένα αρχείο δεν υπάρχει ή δεν περιέχει τις απαιτούμενες στήλες.

**Προσοχή:** Το πλήθος δειγμάτων ανά κατάσταση (`FORWARD`, `SLOW`, `TURN`) δεν αποτελεί μέτρηση χρόνου σε δευτερόλεπτα. Επίσης, η τιμή του `bumper_events` δεν αποτελεί πραγματική μέτρηση συγκρούσεων στην αρχική έκδοση.

Από τον βασικό φάκελο του repository εκτελέστε:

```powershell
python create/tools/analyze_csv.py create/results/run_sparse_065.csv
```

Για πολλά αρχεία:

```powershell
python create/tools/analyze_csv.py create/results/run_sparse_065.csv create/results/run_medium_065.csv create/results/run_dense_065.csv
```

Το πρόγραμμα εμφανίζει τα βασικά αποτελέσματα της καταγραφής.

Μετά την ολοκλήρωση του TODO 5 θα εμφανίζει και την ελάχιστη έγκυρη εμπρόσθια απόσταση LiDAR.

Μετά την ολοκλήρωση του TODO 6 θα δημιουργεί επιπλέον ένα γράφημα για κάθε αρχείο CSV.

## Συνήθη προβλήματα

- **`NotImplementedError`:** Δεν έχει ολοκληρωθεί κάποιο TODO.
- **`getDevice` returns None:** Ελέγξτε το όνομα του αισθητήρα στο Scene Tree.
- **Δεν ενημερώνεται ο controller:** Αποθηκεύστε το Python αρχείο και κάντε Reset.
- **Σφάλμα PROTO:** Ελέγξτε την πρόσβαση στους επίσημους πόρους του Webots.
- **Εμφανίζεται αρχείο `.c`:** Αφορά βοηθητικό controller του αρχικού παραδείγματος. Ο controller της εργασίας είναι σε Python.
